# Family Altar

This repository contains the code for the Family Altar mobile app that digitises the 3 Family Altar books by Brother Tim Dodd.

App is available for download on Android and iOS here: https://family-altar-64288.web.app

The Architecture follows CLEAN architecture using the BLoC pattern.
